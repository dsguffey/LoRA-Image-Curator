MICROSOFT FLORENCE-2 LARGE FT — NATIVE TRANSFORMERS CONVERSION
-------------------------------------------------------------

Model developer: Microsoft
Native checkpoint publisher: Florence-2 Community on Hugging Face
Model: florence-community/Florence-2-large-ft
Pinned revision: 26b734a54fdfbf9c398351eedfabb7f27fc470b7
Model license: MIT
Execution library: Transformers 4.56.2 (Apache License 2.0)

LoRA Image Curator does not bundle the model weights. When Florence is started,
Transformers obtains the pinned native-compatible conversion from Hugging Face
or uses matching cached files. The conversion retains Microsoft's weights and
MIT license while adding the processor/config metadata expected by native
Transformers. The application explicitly disables repository-code execution,
uses Transformers' native Florence-2 implementation, and requires the
snapshot's safetensors weight file.

Official sources:
https://huggingface.co/florence-community/Florence-2-large-ft
https://huggingface.co/microsoft/Florence-2-large-ft
https://huggingface.co/docs/transformers/model_doc/florence2

ONNX RUNTIME
------------

License: MIT

Official source:
https://github.com/microsoft/onnxruntime

LoRA Image Curator's optional installer selects an ONNX Runtime line based on the CUDA
major version bundled with the existing PyTorch installation. Microsoft notes
that ONNX Runtime GPU 1.27 and later use CUDA 13 by default, while earlier
current releases use CUDA 12.

Compatibility documentation:
https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html


EXTERNAL FFMPEG EXECUTABLE
--------------------------

LoRA Image Curator v0.17.0 can invoke a separately installed FFmpeg executable for
local video-frame extraction. LoRA Image Curator does not include, download, update,
link against, copy, or relicense FFmpeg binaries or source code.

The FFmpeg project states that FFmpeg is LGPL 2.1-or-later by default. If a build
uses optional GPL components, GPL 2.0-or-later applies to all of that FFmpeg
build. FFmpeg's legal page also distinguishes nonfree configurations and
provides a distribution-compliance checklist.

Official source:
https://ffmpeg.org/legal.html

Any future decision to distribute an FFmpeg build with LoRA Image Curator must review
that exact build configuration and provide the required matching source,
notices, and other compliance materials. No bundled build is approved by this
document.
