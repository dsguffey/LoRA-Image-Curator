LORA IMAGE CURATOR — RETIRED PORTABLE SOURCE PACKAGE
====================================================

The previous Portable Source package is retired. It required a separately
installed system Python and is no longer a supported installation route.

For a new Windows installation, use LIC Install Manager from the official
GitHub Releases page:

https://github.com/dsguffey/LoRA-Image-Curator/releases

LIC Install Manager Lite includes the Manager, LoRA Image Curator, a private
CPython runtime, and the verified artifacts required to install LIC Core
offline. Optional Florence, MediaPipe, Face Analysis, and FFmpeg components
remain explicit choices in the Manager.

This filename is retained only so historical source archives can be identified.
It is not current setup guidance. See the repository README for current
installation information and the project issue tracker for support.
